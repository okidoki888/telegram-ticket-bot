# ✅ Чек-лист развертывания Telegram Ticket Bot

## Предварительная проверка

### Системные требования
- [ ] Ubuntu 20.04+ или Debian 11+
- [ ] 2+ GB RAM (рекомендуется 4+ GB)
- [ ] 20+ GB свободного места на диске
- [ ] Доступ в интернет с портами 80, 443

### Программное обеспечение
- [ ] Docker 20.10+ установлен
- [ ] Docker Compose 2.0+ установлен
- [ ] Git установлен
- [ ] Curl установлен
- [ ] Пользователь в группе docker

### DNS и домен
- [ ] Доменное имя настроено (например, DuckDNS)
- [ ] DNS запись указывает на ваш сервер
- [ ] Порты 80 и 443 открыты в firewall

## Telegram настройка

### Бот
- [ ] Бот создан через @BotFather
- [ ] Токен бота получен и сохранен
- [ ] Бот добавлен в целевую группу
- [ ] Боту даны права администратора с разрешениями:
  - [ ] Отправка сообщений
  - [ ] Удаление сообщений
  - [ ] Чтение всех сообщений

### Идентификаторы
- [ ] ID группы (chat_id) получен
- [ ] ID треда назначения (sink_topic_id) получен
- [ ] ID исходных тредов (source_topic_ids) получены

## Проект

### Файлы
- [ ] Репозиторий склонирован
- [ ] `.env` файл создан из `env.example`

  - [ ] `CHAT_ID`
  - [ ] `SINK_TOPIC_ID`
